Change which stocks you track

  1. Repo → open state/my_stocks.csv → pencil icon (Edit). Or tap Edit my stocks on the My stocks tab.
  2. One stock per line: ticker,kind,note. Kind is holding (you own it) or watch (just keep an eye on it). Example: AVGO,watch,AI networking
  3. Commit changes. The next update picks it up. Typos are flagged on the dashboard and never break the run.

If it fails

Open GitHub → your repo → Actions → tap the red ✕ run → tap the failed step to read the error. Then:
"Get Pages site failed" / "Not Found" at the deploy step
Pages isn't on. Do step 2 (Source must say GitHub Actions, not "Deploy from a branch"), then re-run.
"Permission denied" or "403" at the Commit step
The Action can't save. Do step 4 (Read and write permissions), then re-run.
"403 Forbidden" from sec.gov / lots of "SEC download failed"
The SEC needs a real contact. Check step 3: the secret value must look like SemiScope you@example.com.
Actions tab is empty / no "Update SemiScope" workflow
The hidden .github folder didn't upload. Add file → Create new file → name it .github/workflows/update.yml → paste the file's contents → Commit.
"Run tests" step is red
A file is missing or got changed. Re-upload all files from the zip. If it's still red, copy the last 30 lines of the error and paste them to Claude.
Missing secret: the run works but data looks thin
Without the secret, the email in config.py is used. If you see SEC failures under How it works → Data health, add the secret (step 3).
